# Action 02: green

Goal: the new test passes, nothing else breaks.

1. Write the **minimum** production code that makes the failing test pass. No anticipation, no "while I'm here".
2. Put the code where the project's architecture says it belongs (layering and conventions come from the stack plugin or the project memory).
3. Do not touch the tests. If one looks wrong, stop and report it.
4. Run the **whole suite**: the new test passes and no other test fails.

Report: files touched, suite result. Update the plan's step status to `green` if a plan tracks it.
